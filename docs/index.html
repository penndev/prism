使用说明

1. 安装

  • Windows：运行 Prism-windows-amd64-installer.exe，按向导安装后从开始菜单打开。
  • macOS：打开 Prism-darwin-arm64.dmg，把 Prism 拖进「应用程序」。

包目前未做代码签名。Windows 可能弹出 SmartScreen，选「仍要运行」。macOS 若提示无法验证开发者：系统设置 → 隐私与安全性 → 仍要打开。

2. 添加节点

主界面下方「添加节点」，填这些即可：

  • 地址：host:port，例如 1.2.3.4:1080
  • 协议：socks5 / socks5s（TLS）/ http / https
  • 用户名 / 密码：节点需要认证再填
  • 备注：可选，方便辨认

批量导入：点节点列表右上角编辑按钮，浏览器会打开订阅页。支持 Prism 订阅、Shadowrocket 订阅，以及桌面导出的 JSON。解析预览确认后才会覆盖当前列表。

3. 连接

  1. 在节点列表里点选一个节点。
  2. 上方代理面板会出现当前节点。
  3. 选模式：
  • 手动模式：只在本机开一个本地代理端口，浏览器或其他软件自己填代理。
  • TUN 模式：创建虚拟网卡接管系统流量。必须先选好节点；Windows 需要能加载 wintun，失败时用管理员身份再开一次。

4. 本地代理（手动模式）

右侧设置 → 本地代理：

  • IP：127.0.0.1 仅本机；0.0.0.0 允许局域网设备连进来。
  • 端口：默认 1080。被占用就换一个。
  • 用户名 / 密码：可选。填了之后，连这个本地端口也要带同样的账号。

浏览器或系统代理一般填：

协议 SOCKS5
主机 127.0.0.1
端口 1080

5. 分流规则

选好节点后，代理面板右上角漏斗图标会打开规则页（地址形如 http://127.0.0.1:1080/rule/）。

地域规则四种模式互斥：

  • 全局代理
  • 全不代理
  • 代理某些区域
  • 绕过某些区域

后两种要先准备 IP 库 ipregion.db，可在规则页下载或上传。库文件说明见 penndev/gopkg ipregion。

域名规则：一行一个域名。写 google.com 时 www.google.com 也会命中。

6. 其它设置

  • 测速域名：测全部节点延迟时用。不填则无法测速。
  • 测速后自动排序：测完按延迟从低到高排。
  • 语言 / 主题：中文、English；浅色、深色、跟随系统。
  • 开机启动：登录系统后自动打开 Prism。
  • 日志开关：打开后窗口底部出现状态日志、连接日志和流量。

7. 常见问题

规则页或订阅页打不开
先在设置里填一个有效的本地端口，并保证 Prism 正在运行。
TUN 开不起来
确认已选节点。Windows 用管理员启动；仍失败就检查是否拦截了虚拟网卡。
改了设置好像没保存
设置是改完自动写入的。关掉再开应能看到上次的值。
测速全失败
设置里的测速域名要能从该节点访问，例如 google.com 或 host:port。
